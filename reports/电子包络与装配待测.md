# 电子包络与装配版待测

当前仅完成固定试握件。目标功能记录为 **PAW3950、2.4 GHz无线1000 Hz、左右主键、中键/滚轮、两个拇指侧键**。这些功能尚未实现或验证。

候选供体严格按用户称呼记录为 **“ATK 蜻蜓 A1 Plus”**，或半组装自主主板。现无可靠实物尺寸/型号确认；不替换成其他型号，不认定该供体使用PAW3950。

## 已发现的干涉与实际含义

本轮对每个包络与组成试握件的CAD部件求交，记录大于0.05 mm³的交叠；另对包络之间做轴对齐包围盒求交。完整数值保留在JSON，下面给出需要处理的事项。

| 位置 | 已发现 | 装配版处理 |
|---|---|---|
| 滚轮旋转区 | 与固定滚轮、固定轴重叠 | 属于本轮有意的触感占位；删除占位并重新设计真实滚轮及中键机构 |
| 编码器 | 与固定轴、左滚轮支撑筋重叠 | 仅删固定轮不够；改变支撑走向或编码器布局，按实际轴高重建 |
| 中键机构 | 与右滚轮支撑筋重叠 | 重新安排中键承力与滚轮支撑，不能削断后直接使用 |
| 两侧键板 | 与左主键后支柱、内侧承力垫、侧向连接及后侧键连接重叠 | 改侧键板位置/板型或采用分体方案，再设计可动侧键与固定点 |
| 电源开关 | 与右后低骨架重叠（约2.693 mm³） | 移动开关或在重新验证刚度后调整该段骨架 |
| 天线净空 | 与估计主板重叠约378 mm³、与电池重叠约189 mm³ | 当前电子布局不合格；先移动天线/电池、改变板形或布局，必要时增加壳体空间 |
| 线束 | 与主板包络约68 mm³、左开关包络约10 mm³交叠 | 明确板上/板下走线和弯曲余量，不能把这些交叠当成已通过 |
| 电池与插头、传感器板/芯片/镜头 | 粗包络有嵌套/交叠 | 可能来自占位范围定义，不能据此断言真实零件必碰或可装；需要真实零件几何替换 |

其他包络与当前打印骨架未检出体积交叠，只说明在这组**估计尺寸与位置**下没有碰到模型。它不证明零件能装进去、能够固定、能够插拔、具有足够公差或满足散热/射频/走线要求。电池和天线当前处于开放后区，装配版还需电池固定与保护结构。

如果供体主板长宽或其元件高度明显超出预留空间，应先选合适板型或改布局；不能为了硬塞供体而切断夹持筋、滚轮支撑或按键受力路径。是否需要增加长度、握宽或高度，应结合V0.1试握结果重新决定。

## 传感器轴线与镜头高度尺寸链

预布局光轴沿Z，垂直于鼠标垫。光轴中心暂放(0,-48)，只是可编辑参考位置。未用上游KiCad封装锚点代替真实光轴坐标。

统一基准：脚贴**粘接平台**为Z=0。令实际脚贴+胶层在使用状态下的总厚度为 `t_skate`，则鼠标垫平面为 `Z=-t_skate`。令PCB安装后底面高度为 `h_PCB_bottom`，真实镜头资料定义的光学参考面位于该底面向下 `d_PCB_to_optical_datum`，则：

```text
z_optical_datum = h_PCB_bottom - d_PCB_to_optical_datum
H_datum_to_pad  = h_PCB_bottom - d_PCB_to_optical_datum + t_skate
```

若量的是PCB顶面，还要先减去实测板厚得到PCB底面高度。安装座高度、镜头卡扣/定位台阶、壳体底面、脚贴和胶层压缩量、打印误差都要纳入尺寸链；最终H必须满足**实际传感器+实际镜头组合**的资料及验收要求。

`olliebella`的约2.4±0.2 mm是它自己的结构设定，本轮未将其当成通用PAW3950规范。当前镜头框的中心Z=2.6也不是已经校准的光学工作高度。

## 装配版待测尺寸与证据

| 对象 | 下一轮至少需要 |
|---|---|
| 供体身份 | 包装/底标/软件中的完整型号、硬件修订、PCB正反面清晰照片；实际传感器丝印或可靠型号证据 |
| 主PCB | 带比例尺的正反面图或扫描；外轮廓、板厚、所有孔中心XY与孔径、孔到板边；最高元件及其区域、定位柱/卡扣 |
| 传感器/镜头 | 准确型号和机械资料；光轴相对板基准的XY；镜头最大轮廓、PCB到镜头参考面高度、锁止结构和装配方向 |
| 左右开关 | 准确型号、外形、焊接后顶面高度、触点/柱位置、按压行程及预压要求 |
| 滚轮/编码器/中键 | 轮外径/宽、轴径或六角截面、左右轴肩、编码器轴高、焊接高度、轮胎间隙、中键支承与动作行程 |
| 两侧键板 | 板形/板厚、孔位、两个开关顶点XYZ、触发行程、连接器方向、线束/排线长度与弯曲余量 |
| 电池/插头 | 包覆后实际最大长宽厚、出线点、连接器型号/极性/插拔方向、保护板区域、合理余量与固定方式 |
| USB-C | 连接器金属壳和PCB位置、接口相对基准高度、常用线头外模尺寸与插拔直线空间 |
| 电源开关 | 本体、焊脚、拨杆位置/行程及可操作方向 |
| 天线 | 类型、在板上位置、实际板方推荐净空；与电池/金属/铜皮的限制，匹配接收器情况 |
| 脚贴与底面 | 五片脚贴+胶层的实际厚度、压缩后高度、底面平面度；决定最后镜头尺寸链 |

无线1000 Hz需要完整主板、相应固件、匹配接收器一起确认。机械装配通过之后，另验收回报率、滚轮/按键功能、传感器追踪与实际抬升表现；本轮不提前宣称这些目标已达成。
