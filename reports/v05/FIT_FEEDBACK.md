# V0.5 试握反馈表

打印版本：FIT / SHELL+独立键帽；材料：____；喷嘴/层高：____；脚贴直径和厚度：____；日期：____。

本轮不评价真实点击力度、回弹、滚轮阻尼、无线延迟或电子件重心。先确认支撑清干净、五脚同厚、窗口无毛刺。

| 项目 | 记录方式 | 当前反馈 |
|---|---|---|
| 握宽 | 太窄/合适/太宽；自然夹持点距前端大约多少；与V0.4相比是否仍然自然 | ____ |
| 平顺侧面 | 指肚是否能前后移动；是否希望保留更浅的凹陷或增加纹理 | ____ |
| 顶掌 | 前后拉鼠时尾部是否碰掌；碰到哪里；需要缩短还是降低 | ____ |
| 无名指/小指拖地 | 哪根手指拖地；托边是否硌指或妨碍抬鼠 | ____ |
| 低前端与缓升键面 | 手指是否更放松；是否感觉过低；是否需改变键面坡度 | ____ |
| 底边过渡 | Z6附近过渡边是否能摸到、是否硌指；底部结构不变 | ____ |
| 滚轮触达 | 食指/中指能否自然碰到；需要前后/上下移动多少 | ____ |
| 前侧键触达 | 拇指是否需要伸直或换握；希望更前/后/高/低 | ____ |
| 后侧键触达 | 是否误碰；与前键能否盲辨；两键间距是否合适 | ____ |
| 键面形状 | 10.8 ×5.4是否足够；R1.1边缘是否舒服；突出量是否过大 | ____ |
| 分体接口 | 是否可由底部装入；哪个位置发涩；窗口/限位边需多少修整 | ____ |
| 抬鼠稳定性 | 轻抬时是否前后滑动、扭转；是否需要过度夹紧 | ____ |
| 后壳孔阵 | 指尖是否碰孔边；孔的视觉密度是否合适；边缘孔是否贴合外形；3—4—3密度是否合适 | ____ |
| 细筋形变 | 同样轻夹或抬鼠时，后壳筋是否明显发软或扭转；有无白化、开裂 | ____ |
| 去支撑 | 贴合支撑是否容易从底部清除；是否误碰孔间筋或留下毛刺 | ____ |
| 刚度与打印 | 侧壁、键帽固定桥、轮架、底筋、尾根是否发白/开裂/缺料 | ____ |
| 五脚 | 平板上是否晃动；是哪一个脚；先检查首层和脚贴厚度 | ____ |

附照片建议：自然指握俯视、拇指侧、无名指/小指侧各一张，放置尺子作比例参考。不要把再次估计的张开跨度当成掌宽；如果能量到实际掌宽和指节，再作为独立输入。
