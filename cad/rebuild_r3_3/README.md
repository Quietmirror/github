# R3.3 / r3_3 工程入口

R3.3 将此前 L2 研究成果纳入 R3 系列，公开存放在仓库 main。版本标识为 `r3_3`，发布目录为 `releases/Fenrir-MiniSE-R3.3`。

本次只整理发布路径、文件名、首页和版本索引，几何没有变化。可编辑参数化源码继续位于 [cad/l2_revision](../l2_revision/README.md)，模型内部 F1H、L2_H_EST、L2_D_EST 等编号保留，方便与原始检查报告对应。

在完整仓库中运行下列命令，可用现有的 L2 发布包重新生成 R3.3 目录。此步骤只需要 Python 标准库；不重新计算 CAD、有限元或切片。

```powershell
python cad/rebuild_r3_3/package.py
```

`R3_3_SOURCE.zip` 包含 R3.3 入口、L2 参数化研究源码及 R2/R3 系列源代码依赖，供完整仓库使用；CAD 运行时和历史基准包仍按原项目说明单独准备。重新生成几何的命令、依赖及验证顺序见上方 L2 源码说明。

共用件九件；H、D 各十一件；两套转接件合板十三件。重命名没有消除原有问题：14.89 g 目标未达到，H 托架装入路径未通过，D 供体未核实且测量板有干涉，实物点击、无线和续航未验证。
